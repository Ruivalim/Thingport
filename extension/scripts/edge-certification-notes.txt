WHAT IT DOES
Imports 3D-printing models from MakerWorld, Printables, Thingiverse and, once turned on, MyMiniFactory into the user's own self-hosted Thingport server (open source: https://github.com/TautvydasDerzinskas/Thingport). It has no servers of its own and sends nothing to the developer or any third party.

HOW TO TEST
1. A Thingport server is required. {{testServer}}
2. Click the toolbar icon, enter the server address, email and password, and connect. Allow the access request for that address.
3. Open a model page, e.g. https://www.printables.com/model/3161-3d-benchy or https://makerworld.com/en/models/3080401, click the Thingport button at the bottom right of the page and choose Import. The model appears in the Thingport web app and under Recent imports in the toolbar popup.
4. MakerWorld downloads need a MakerWorld login in the same browser; Printables and Thingiverse work without one.

PERMISSIONS
- storage: the server address, sign-in and recent imports.
- cookies: reads the MakerWorld session cookie, on makerworld.com only, which MakerWorld requires for downloads, and the MyMiniFactory session cookie, on myminifactory.com only, which downloads the user's bought models from their own library. Both are sent only to the user's own server.
- downloads: reads the link from a download MakerWorld's page starts, then cancels it.
- scripting: registers the content script on MyMiniFactory, and on model sites added in later versions, once the user allows them.
- host access: the three model sites; the user's own server address (requested at setup); and, optionally, all websites, requested only when the user clicks "Turn on" under More sites in the popup, so model sites added in later versions need no new permission. The content script is only ever registered on supported model sites.

The code isn't minified or obfuscated. Documentation: https://thingport.net/docs/grab/ Privacy policy: https://github.com/TautvydasDerzinskas/Thingport/blob/main/extension/PRIVACY.md
